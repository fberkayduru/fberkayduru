### Investment Research Agent System

Three autonomous agents for equity research and portfolio monitoring, built with the Anthropic Claude API.

| Agent | What it does |
|-------|-------------|
| **Research Agent** | Generates a 12-section institutional-quality research report on any company — management, financials, competitive landscape, supply chain, comps, and more — powered by live web research |
| **Monitor Agent** | Extracts the 5–8 most important business drivers from a research report and tracks them weekly via web search, flagging material changes green / yellow / red. Includes a milestone calendar with dated events and bull/bear trigger definitions |
| **Media Agent** | Scans weekly media appearances of a curated watchlist — investors, semiconductor/AI company executives, and frontier-lab researchers — summarizes each with investment-focused notes, then synthesizes cross-cutting themes |

**→ [fberkayduru/analyst-agent](https://github.com/fberkayduru/analyst-agent)**

**Stack:** Python · Anthropic API · DuckDuckGo search · BeautifulSoup · Rich
